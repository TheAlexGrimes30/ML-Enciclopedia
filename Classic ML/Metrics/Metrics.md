## 📏 Метрики машинного обучения

Раздел **Metrics** посвящён ключевым способам оценки качества моделей машинного обучения.  
Здесь собраны метрики как для **классификации**, так и для **регрессии**, с математическим обоснованием и примерами вычислений.

---

### 🎯 Цель раздела

Понять, **что именно измеряет каждая метрика**, и как её интерпретировать в контексте качества модели.  
Каждая метрика сопровождается:
- 📘 **Формулой и объяснением** — что и как она измеряет.  
- 💻 **Примером расчёта вручную и через Python**.  
- 🔬 **Сравнением с поведением модели** на разных данных.

### 🔹 Метрики для классификации

#### **Accuracy (точность)**
- Доля правильно классифицированных объектов.
- Формула:  
$
\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}
$

#### **Balanced Accuracy (сбалансированная точность)**
- Среднее арифметическое точности по каждому классу, полезна при несбалансированных данных.
- Формула:  
$
\text{Balanced Accuracy} = \frac{1}{2} \left(\frac{TP}{TP + FN} + \frac{TN}{TN + FP}\right)
$

#### **Precision (точность для положительного класса)**
- Доля корректно предсказанных положительных объектов среди всех предсказанных как положительные.
- Формула:  
$
\text{Precision} = \frac{TP}{TP + FP}
$

#### **Recall (полнота, чувствительность)**
- Доля корректно предсказанных положительных объектов среди всех реальных положительных.
- Формула:  
$
\text{Recall} = \frac{TP}{TP + FN}
$

#### **F1 Score**
- Гармоническое среднее Precision и Recall.
- Формула:  
$
F1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
$

#### **ROC AUC**
- Площадь под кривой ROC, показывает способность модели различать классы.
- Диапазон: [0, 1], чем ближе к 1 — тем лучше.

### 🔹 Метрики для регрессии

#### **R² (коэффициент детерминации)**
- Доля объяснённой дисперсии.
- Формула:  
$
R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}
$

#### **MSE (Mean Squared Error)**
- Среднеквадратичная ошибка.
- Формула:  
$
MSE = \frac{1}{n} \sum_i (y_i - \hat{y}_i)^2
$

#### **MAE (Mean Absolute Error)**
- Средняя абсолютная ошибка.
- Формула:  
$
MAE = \frac{1}{n} \sum_i |y_i - \hat{y}_i|
$

### 🔹 Метрики для кластеризации
#### **Silhouette Score (силуэтный коэффициент)**
- Оценивает насколько объект похож на свой кластер (когезия) по сравнению с другими кластерами (сепарация).

- Значения от -1 до 1, где 1 — идеальное разделение, 0 — пересекающиеся кластеры, -1 — неправильное назначение.

- Средний силуэт по всем объектам — общая оценка кластеризации.

Формула для одного объекта:

$
s(i) = \frac{b(i) - a(i)}{\max{a(i), b(i)}}
$

где $a(i)$ — среднее расстояние до объектов в том же кластере, $b(i)$ — среднее расстояние до объектов в ближайшем соседнем кластере.



#### **Inertia (инерция / сумма квадратов расстояний)**
 - Сумма квадратов расстояний от объектов до центроидов их кластеров.

- Используется как функция потерь в K-Means.

- Чем меньше значение — тем компактнее кластеры, но есть риск переобучения при большом числе кластеров.

Формула:
$
\text{Inertia} = \sum_{i=1}^{k} \sum_{x \in C_i} | x - \mu_i |^2
$

где $C_i$ — кластер $i$, $\mu_i$ — его центроид.

#### **Adjusted Rand Index (скорректированный индекс Рэнда)**
- Сравнивает предсказанную кластеризацию с истинной (если известна), учитывая случайное угадывание.

- Значения от -1 до 1, где 1 — полное совпадение, 0 — случайное соответствие, отрицательные значения — хуже случайного.

Формула:
$
ARI = \frac{\text{RI} - \text{Expected_RI}}{\max(\text{RI}) - \text{Expected_RI}}
$

где RI — обычный индекс Рэнда (доля пар объектов, согласованных по кластерам в двух разбиениях).
