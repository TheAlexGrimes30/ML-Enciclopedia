# ⚡ Gradient Boosting — Gradient Boosted Trees

## 1️. Основная идея

**Gradient Boosting** — это ансамблевый метод, который строит последовательность моделей,  
каждая из которых исправляет ошибки предыдущих, минимизируя функцию потерь через **градиентный спуск**.

- Базовые модели обучаются **последовательно**.  
- Каждая следующая модель прогнозирует **остатки (residuals)** предыдущих моделей.  
- Итоговое предсказание — **сумма предсказаний всех моделей**, обычно с весовым коэффициентом (learning rate).

---

## 2️. Формулы ансамбля

### Итоговое предсказание

Для регрессии с функцией потерь $(L(y, F(x))$):

$
F_0(x) = \arg\min_{\gamma} \sum_{i=1}^{N} L(y_i, \gamma)
$

На каждом шаге $m = 1, \dots, M$:

1. Вычисляем градиент (остатки):
$
r_i^{(m)} = -\left[ \frac{\partial L(y_i, F(x_i))}{\partial F(x_i)} \right]_{F(x)=F_{m-1}(x)}
$

2. Обучаем базовую модель $h_m(x)$ на остатках $r_i^{(m)}$.

3. Находим оптимальный коэффициент $\gamma_m$:
$
\gamma_m = \arg\min_{\gamma} \sum_{i=1}^{N} L(y_i, F_{m-1}(x_i) + \gamma h_m(x_i))
$

4. Обновляем ансамбль:
$
F_m(x) = F_{m-1}(x) + \eta \gamma_m h_m(x)
$

где $\eta$ — **learning rate**, контролирующий вклад каждой модели.

---

### Для классификации (binary, log-loss)

1. Функция потерь — логистическая:
$
L(y, F(x)) = \log(1 + e^{-2yF(x)}), \quad y \in \{-1, 1\}
$

2. Остатки:
$
r_i^{(m)} = \frac{2 y_i}{1 + e^{2 y_i F_{m-1}(x_i)}}
$

3. Ансамбль обновляется так же:
$
F_m(x) = F_{m-1}(x) + \eta \gamma_m h_m(x)
$

---

## 3️. Механизм обучения

1. Инициализация модели постоянной величиной \(F_0(x)\) — обычно среднее по целевой переменной.  
2. Для каждой итерации $m = 1, \dots, M$:  
   - Вычисляются остатки (градиенты) $r_i^{(m)}$  
   - Обучается базовая модель $(h_m(x)$ на этих остатках  
   - Находится оптимальный коэффициент $\gamma_m$  
   - Обновляется ансамбль $F_m(x)$ с learning rate $\eta$  
3. Итоговое предсказание — сумма всех моделей:  
$
\hat{y}(x) = F_M(x) = F_0(x) + \sum_{m=1}^{M} \eta \gamma_m h_m(x)
$

---

## 4️. Преимущества и недостатки Gradient Boosting

### ✅ Преимущества

1. **Высокая точность и гибкость**  
   Отлично подходит для табличных данных и сложных зависимостей.

2. **Обработка разных функций потерь**  
   Можно использовать для регрессии, классификации, ранжирования.

3. **Фокусировка на сложных примерах**  
   Каждая модель исправляет ошибки предыдущих.

4. **Регуляризация через learning rate и subsampling**  
   Помогает избежать переобучения.

5. **Можно контролировать сложность ансамбля**  
   Через глубину деревьев, число итераций и learning rate.

---

### ❌ Недостатки

1. **Последовательное обучение**  
   Не распараллеливается так эффективно, как Bagging.

2. **Чувствителен к выбросам**  
   Ошибки могут накапливаться.

3. **Требует тщательной настройки гиперпараметров**  
   Learning rate, max_depth, n_estimators и subsample.

4. **Медленный на больших наборах данных**  
   Особенно при глубоком дереве и большом числе итераций.
