# Gradient Boosting Libraries: CatBoost, XGBoost, LightGBM

## 1. Общие принципы градиентного бустинга

Градиентный бустинг — это ансамблевый метод машинного обучения, который строит модель как сумму слабых моделей (обычно деревьев решений), обучаемых последовательно. Каждая новая модель аппроксимирует **отрицательный градиент функции потерь** относительно текущих предсказаний.

Общая формула:

$$F_m(x) = F_{m-1}(x) + η · h_m(x)$$

где:
- F_m(x) — ансамбль на шаге m  
- h_m(x) — новое дерево  
- η — learning rate  

Классическая реализация (Friedman, 2001):
- CART-деревья  
- Level-wise рост деревьев  
- Использование MSE / LogLoss  

Современные библиотеки развивают эту идею, решая проблемы **скорости, переобучения и работы с большими данными**.

## 2. XGBoost (Extreme Gradient Boosting)

### 2.1 Принцип работы

XGBoost — это оптимизированная реализация градиентного бустинга с использованием **второго порядка производных (Hessian)**.

Оптимизируемая функция:

$$L = Σ l(y_i, ŷ_i) + Σ Ω(f_k)$$

Регуляризация:

$$Ω(f) = γT + (1/2)λ‖w‖²$$

### 2.2 Архитектурные особенности

- Level-wise рост деревьев  
- Использование градиента и гессиана  
- Явная L1 / L2 регуляризация  
- Efficient split finding (hist, approx)  
- Out-of-core computation  

### 2.3 Отличия от классического GB

| Классический GB | XGBoost |
|----------------|--------|
| Только градиент | Градиент + гессиан |
| Нет регуляризации | L1 / L2 |
| Медленный | Оптимизированный C++ |

### 2.4 Преимущества

- Высокая точность  
- Отличный контроль переобучения  
- Гибкая настройка  

### 2.5 Недостатки

- Большое число гиперпараметров  
- Требует тщательного тюнинга  
- Неэффективен для категориальных признаков

## 3. LightGBM (Light Gradient Boosting Machine)

### 3.1 Принцип работы

LightGBM ориентирован на **скорость и масштабируемость**, особенно для больших датасетов.

### 3.2 Архитектурные особенности

- Leaf-wise рост деревьев  
- Histogram-based splitting  
- GOSS (Gradient-based One-Side Sampling)  
- EFB (Exclusive Feature Bundling)  

### 3.3 Отличия от классического GB

| Классический GB | LightGBM |
|----------------|----------|
| Level-wise рост | Leaf-wise рост |
| Полные данные | GOSS |
| Нет feature bundling | EFB |

### 3.4 Преимущества

- Очень высокая скорость обучения  
- Эффективное использование памяти  
- Отлично масштабируется  

### 3.5 Недостатки

- Склонность к переобучению на малых данных  
- Требует аккуратного тюнинга  
- Менее интерпретируем  

---

## 4. CatBoost (Categorical Boosting)

### 4.1 Принцип работы

CatBoost разработан для эффективной работы с **категориальными признаками** без явного one-hot encoding.

Ключевая идея — **Ordered Boosting**, устраняющий target leakage.

### 4.2 Архитектурные особенности

- Symmetric (oblivious) trees  
- Ordered Target Statistics  
- Ordered Boosting  
- Встроенная обработка категориальных признаков  

### 4.3 Отличия от классического GB

| Классический GB | CatBoost |
|----------------|----------|
| CART-деревья | Симметричные деревья |
| One-hot encoding | Target statistics |
| Риск leakage | Ordered boosting |

### 4.4 Преимущества

- Отличная работа с категориальными признаками  
- Минимальный preprocessing  
- Стабильность без сложного тюнинга  

### 4.5 Недостатки

- Более медленный inference  
- Больший размер модели  
- Ограниченная гибкость деревьев

## 5. Сравнительная таблица

| Характеристика | XGBoost | LightGBM | CatBoost |
|---------------|--------|----------|----------|
| Рост дерева | Level-wise | Leaf-wise | Symmetric |
| Категориальные признаки | ❌ | ⚠️ | ✅ |
| Скорость | Высокая | Очень высокая | Средняя |
| Тюнинг | Сложный | Средний | Минимальный |
| Переобучение | Контролируемое | Возможное | Минимальное |

---

## 6. Итоговые выводы

- **XGBoost** — максимальная точность и контроль  
- **LightGBM** — лучший выбор для больших данных и скорости  
- **CatBoost** — оптимален при наличии категориальных признаков
