# 🪄 Bagging — Bootstrap Aggregating

## 1️. Основная идея

**Bagging (Bootstrap Aggregating)** — это ансамблевый метод, направленный на **снижение дисперсии** модели за счёт усреднения результатов нескольких базовых моделей, обученных на разных бутстрэп-выборках данных.

- Каждая модель обучается на случайной подвыборке данных (с возвращением).  
- Итоговое предсказание — **усреднение** (для регрессии) или **голосование** (для классификации).  

---

## 2️. Формулы ансамбля

**Для регрессии:**

$
\hat{y}(x) = \frac{1}{M} \sum_{m=1}^{M} f_m(x)
$

**Для классификации:**

$
\hat{y}(x) = \text{mode}\{f_1(x), f_2(x), \ldots, f_M(x)\}
$

---

## 3️. Bootstrap-процедура

1. Из `N` объектов обучающей выборки случайно выбираются `N` элементов **с возвращением**.  
2. Каждая бутстрэп-выборка содержит примерно 63% уникальных объектов (остальные — повторяются).  
3. Примерно **37% данных не попадают** в подвыборку — это **Out-of-Bag (OOB)** наблюдения.  
4. **OOB**-данные можно использовать для оценки точности ансамбля без отдельной валидации.

---

## 4️. Преимущества и недостатки Bagging

### ✅ Преимущества

1. **Снижение дисперсии модели**  
   Усреднение результатов нескольких моделей делает итоговую модель менее чувствительной к случайным колебаниям данных.

2. **Повышение стабильности и устойчивости**  
   Особенно эффективно для "нестабильных" моделей, например деревьев решений.

3. **Возможность параллельного обучения**  
   Каждая модель обучается независимо, что удобно для распараллеливания на многоядерных системах.

4. **Не требует сложной настройки гиперпараметров**  
   В отличие от бустинга, результаты стабильны даже без тонкой настройки параметров.

5. **Использование OOB-оценки**  
   Позволяет оценить качество ансамбля без выделения отдельной валидационной выборки.

---

### ❌ Недостатки

1. **Снижение интерпретируемости**  
   Ансамбль состоит из множества моделей, и понять, как принимается решение, сложно.

2. **Не снижает смещение (bias)**  
   Если базовые модели систематически ошибаются, Bagging не поможет — он борется только с дисперсией.

3. **Высокие вычислительные затраты**  
   Нужно обучить и хранить множество моделей, что требует больше памяти и времени.

4. **Неэффективен для моделей с низкой дисперсией**  
   Если базовая модель слишком простая (например, линейная регрессия), прирост качества будет незначительным.

5. **Меньшая эффективность при малом объёме данных**  
   Из-за бутстрэп-сэмплирования разнообразие подвыборок может быть недостаточным.

---

## 5️. Применение

- Часто используется с **деревьями решений** → модель **Random Forest** — это разновидность Bagging с дополнительной случайностью в выборе признаков.  
- Подходит для задач, где **уменьшение переобучения** и **стабильность** важнее, чем интерпретируемость.
