## K-Means Clustering

## 🧠 Математическая основа

### 1️⃣ Основная идея
K-Means — алгоритм кластеризации, который делит объекты на K кластеров, минимизируя сумму квадратов расстояний объектов до центроидов своего кластера:

$
\text{argmin}_{C} \sum_{k=1}^{K} \sum_{x_i \in C_k} \| x_i - \mu_k \|^2
$

где:  
- $C_k$ — множество объектов k-го кластера  
- $\mu_k$ — центр (среднее) объектов кластера  

---

### 2️⃣ Шаги алгоритма

1. Инициализация **K центроидов** (случайно или по методу k-means++)  
2. Назначение каждого объекта к ближайшему центроиду:  
$
\text{cluster}(x_i) = \arg\min_k \| x_i - \mu_k \|
$
3. Обновление центроидов:  
$
\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i
$
4. Повторение шагов 2–3 до сходимости (центроиды перестают меняться или достигнуто максимальное число итераций)

---

### 3️⃣ Особенности

- Алгоритм чувствителен к **инициализации центроидов**  
- Требует заранее задать число кластеров **K**  
- Работает быстрее на числовых данных  
- Минимизирует **дисперсию внутри кластеров**, но не гарантирует глобальный минимум
