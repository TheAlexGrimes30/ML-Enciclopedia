## PCA (Principal Component Analysis)

## 🧠 Математическая основа

### 1️⃣ Основная идея
PCA — метод понижения размерности, который преобразует исходные признаки в новый ортогональный базис,  
максимизируя дисперсию данных и минимизируя потерю информации.

Задача PCA формулируется как поиск направлений (главных компонент), вдоль которых проекция данных имеет максимальную дисперсию:

$
\text{argmax}_{\|w\|=1} \; \mathrm{Var}(Xw)
$

где:  
- $X$ — центрированная матрица данных  
- $w$ — направление (вектор главной компоненты)  

---

### 2️⃣ Шаги алгоритма

1. **Центрирование данных** (вычитание среднего):
$
X_c = X - \mu
$

2. **Вычисление ковариационной матрицы**:
$
\Sigma = \frac{1}{n} X_c^\top X_c
$

3. **Собственные значения и собственные векторы** ковариационной матрицы:
$
\Sigma v_i = \lambda_i v_i
$

4. **Сортировка собственных векторов** по убыванию собственных значений  
5. **Выбор первых K компонент**, соответствующих наибольшей дисперсии  
6. **Проекция данных** в новое пространство:
$
Z = X_c W_K
$

где:  
- $W_K$ — матрица из первых $K$ собственных векторов  
- $Z$ — данные в пространстве главных компонент  

---

### 3️⃣ Особенности

- PCA устраняет **коррелированные признаки**  
- Снижает размерность с минимальной потерей информации  
- Требует масштабирования признаков при разном масштабе  
- Линейный метод, не выявляет нелинейные зависимости  
- Главные компоненты не всегда интерпретируемы
