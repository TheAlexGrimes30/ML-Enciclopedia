## Unsupervised Learning

Раздел **Unsupervised Learning** посвящён алгоритмам машинного обучения, которые **работают без меток**.  
Основная цель — **выявление скрытых закономерностей** в данных, группировка объектов и уменьшение размерности.

Каждый метод включает:
- 📘 **Математическое обоснование** — формулы для кластеризации, мер схожести, собственные значения и векторы.  
- 💻 **Реализацию с нуля** — алгоритмы на `NumPy`.  
- 🔬 **Сравнение с `scikit-learn`** — визуализация кластеров, качество разбиения.

### Основные методы

#### K-Means Clustering
- **Идея:** разделить данные на K кластеров, минимизируя расстояние до центроидов.  
- **Цель:** выявить естественные группы объектов.  
- **Шаги алгоритма:**
  1. Инициализация центроидов (случайно или k-means++)  
  2. Назначение каждого объекта к ближайшему центроиду  
  3. Обновление центроидов как среднего по кластеру  
  4. Повторение шагов 2–3 до сходимости

#### DBSCAN
- **Идея:** плотностная кластеризация без необходимости задавать число кластеров.  
- **Цель:** выделять области высокой плотности, игнорируя шум.  
- **Параметры:** eps (радиус соседства), min_samples (минимальное количество соседей)

#### PCA (Principal Component Analysis)
- **Идея:** понижение размерности, сохраняя максимальную дисперсию данных.  
- **Цель:** визуализация, уменьшение вычислительной сложности, удаление шумных признаков  
- **Математика:** собственные значения и собственные векторы ковариационной матрицы данных
