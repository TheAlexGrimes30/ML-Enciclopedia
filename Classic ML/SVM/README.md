# 🧠 Linear SVM / Linear SVR — Реализация с нуля и сравнение с библиотечными решениями

## 📘 Описание проекта
В этом проекте реализованы **Linear SVM (классификация)** и **Linear SVR (регрессия)** с нуля на `NumPy`.  
Поддерживаются:
- **Soft margin** через параметр `C`;
- **Регуляризация L2**;
- Обучение через **стохастический градиентный спуск (SGD)** для линейных моделей;
- Сравнение с готовыми реализациями из **scikit-learn** (`SVC(kernel='linear')` и `LinearSVR`).

Цель — понять **математическую базу, принцип работы и особенности** SVM для классификации и регрессии.

---

## 🧩 Математическая основа

### 1️⃣ Linear SVM (классификация)
Linear SVM ищет **гиперплоскость**, разделяющую классы с **максимальным отступом (margin)**.  

**Гиперплоскость:**
$$
f(x) = w^T x + b
$$

**Функция потерь (hinge loss) для одного объекта:**
$$
L(y, f(x)) = \max(0, 1 - y f(x))
$$

**Функция потерь для всей выборки (soft margin):**
$$
J(w, b) = \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{m} \max(0, 1 - y_i (w^T x_i + b))
$$

где  
- $y_i \in \{-1, 1\}$ — метки классов,  
- $C$ — коэффициент регуляризации, контролирующий штраф за ошибки.

---

### 2️⃣ Linear SVR (регрессия)
Linear SVR использует **ε-insensitive loss**, чтобы игнорировать небольшие ошибки:

**Функция потерь для одного объекта:**
$$
L_\epsilon(y, f(x)) = 
\begin{cases} 
0, & |y - f(x)| \le \epsilon \\
|y - f(x)| - \epsilon, & |y - f(x)| > \epsilon
\end{cases}
$$

**Функция потерь для всей выборки:**
$$
J(w, b) = \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{m} L_\epsilon(y_i, w^T x_i + b)
$$

где  
- $\epsilon$ — зона нечувствительности (погрешность),  
- $C$ — коэффициент регуляризации.

## ⚙️ Обучение моделей

| Модель | Метод обучения | Регуляризация | Особенности |
|:--------|:---------------|:------------:|:------------|
| **Linear SVM** | SGD (Hinge Loss) | ✅ L2 | Простая линейная граница, чувствителен к масштабированию данных |
| **Linear SVR** | SGD (ε-insensitive Loss) | ✅ L2 | Предсказывает непрерывные значения, игнорируя небольшие ошибки |

---

## ⚖️ Преимущества

- **Линейная SVM** и **Linear SVR** просты и интерпретируемы  
- Быстро обучаются на больших выборках  
- Поддерживают L2 регуляризацию (контроль переобучения)  
- SVM обеспечивает **максимальный отступ**, что улучшает обобщающую способность  
- SVR дает возможность **игнорировать малые ошибки** через параметр ε  

---

## ⚠️ Недостатки

- Не подходят для **сильно нелинейных зависимостей** без ядровых трюков  
- Чувствительны к **масштабированию признаков**  
- Для SVM: требует правильного выбора параметра `C`  
- Для SVR: выбор ε сильно влияет на качество модели  
- Могут плохо работать при **сильном шуме** или несбалансированных данных
