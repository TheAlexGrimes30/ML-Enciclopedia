# 🧠 SVM / SVR — Математическая база и обзор

## 🧩 Математическая основа

### 1️⃣ SVM (классификация)
SVM ищет **гиперплоскость**, разделяющую классы с **максимальным отступом (margin)**:  

**Гиперплоскость:**
$$
f(x) = w^T x + b
$$

**Функция потерь (hinge loss) для одного объекта:**
$$
L(y, f(x)) = \max(0, 1 - y f(x))
$$

**Функция потерь для всей выборки (soft margin):**
$$
J(w, b) = \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{m} \max(0, 1 - y_i (w^T x_i + b))
$$

где  
- $y_i \in \{-1, 1\}$ — метки классов,  
- $C$ — коэффициент регуляризации, контролирующий штраф за ошибки.

---

### 2️⃣ SVR (регрессия)
SVR использует **ε-insensitive loss**, чтобы игнорировать небольшие ошибки:

**Функция потерь для одного объекта:**
$$
L_\epsilon(y, f(x)) = 
\begin{cases} 
0, & |y - f(x)| \le \epsilon \\
|y - f(x)| - \epsilon, & |y - f(x)| > \epsilon
\end{cases}
$$

**Функция потерь для всей выборки:**
$$
J(w, b) = \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{m} L_\epsilon(y_i, w^T x_i + b)
$$

где  
- $\epsilon$ — зона нечувствительности,  
- $C$ — коэффициент регуляризации.

---

## 🧬 Ядра SVM/SVR

Ядра позволяют работать с **нелинейными данными**:

| Ядро | Форма | Особенности |
|:-----|:-----|:------------|
| **Линейное** | $K(x, x') = x^T x'$ | Простое, быстрое, для линейно разделимых данных |
| **Полиномиальное** | $K(x, x') = (\gamma x^T x' + r)^d$ | Для сложных зависимостей, контролируется степень $d$ |
| **RBF (Gaussian)** | $K(x, x') = \exp(-\gamma \|x - x'\|^2)$ | Очень гибкое, хорошо для большинства задач |
| **Сигмоидное** | $K(x, x') = \tanh(\gamma x^T x' + r)$ | Иногда работает как NN, но чувствительно к параметрам |

---

## ⚖️ Преимущества

- Высокая **обобщающая способность** благодаря максимальному отступу (SVM);  
- Возможность работы с **нелинейными данными** через ядра;  
- L2 регуляризация помогает бороться с переобучением;  
- SVR позволяет **игнорировать малые ошибки** через ε;  
- Быстро обучаются на средних объемах данных (особенно линейные версии);  
- Интерпретируемы для линейных моделей.

---

## ⚠️ Недостатки

- Чувствительны к **масштабированию признаков**;  
- Параметры `C`, `ε`, `gamma` сильно влияют на качество;  
- Могут плохо работать при **сильном шуме**;  
- Для больших объемов данных с ядровыми методами — **дорого по памяти и времени**;  
- Неинтерпретируемы при сложных ядрах.
