# Faiss

**Faiss (Facebook AI Similarity Search)** — библиотека для быстрого поиска ближайших соседей и кластеризации плотных векторов. Была разработана компанией Meta для работы с большими наборами данных и широко используется в системах поиска по embedding.

Faiss применяется в задачах:

- semantic search
- рекомендательные системы
- поиск похожих изображений
- поиск похожих документов
- системы на основе embedding моделей

### Основная идея

Faiss ускоряет поиск ближайших соседей за счёт использования **специализированных индексов**, которые уменьшают количество сравнений между векторами.

Алгоритм работы зависит от типа индекса, но общий процесс выглядит следующим образом:

1. Векторы добавляются в индекс.
2. Строится структура данных (индекс).
3. Для входного запроса определяется область поиска.
4. Выполняется поиск кандидатов.
5. Из кандидатов выбираются ближайшие соседи.

Faiss может выполнять как **точный поиск**, так и **приближённый поиск ближайших соседей (ANN)**.
