## Approximate Nearest Neighbor Libraries

При работе с большими наборами данных классический алгоритм **K-Nearest Neighbours (KNN)** становится медленным, так как требует вычисления расстояния до каждой точки обучающего набора.

Для ускорения поиска используются библиотеки **Approximate Nearest Neighbor (ANN)**, которые находят ближайших соседей приближённо, но значительно быстрее.

# Annoy

**Annoy (Approximate Nearest Neighbors Oh Yeah)** — библиотека для быстрого поиска ближайших соседей в многомерных пространствах. Была разработана компанией Spotify для построения рекомендательных систем.

### Основная идея

Annoy строит **несколько случайных деревьев**, которые разбивают пространство признаков на области с помощью гиперплоскостей.

Алгоритм работает следующим образом:

1. Все векторы добавляются в индекс.
2. Строится несколько случайных деревьев.
3. Пространство рекурсивно разделяется гиперплоскостями.
4. При поиске алгоритм проходит по деревьям и выбирает кандидатов.
5. Среди кандидатов выбираются ближайшие соседи.

### Поддерживаемые метрики

- Euclidean distance
- Manhattan distance
- Angular distance (cosine)
- Hamming distance
- Dot product

### Преимущества

- Быстрый поиск ближайших соседей
- Низкое потребление памяти
- Возможность сохранения индекса на диск
- Хорошо подходит для рекомендательных систем

### Недостатки

- Поиск является приближённым
- Точность зависит от количества деревьев
- Медленное построение индекса для очень больших данных
