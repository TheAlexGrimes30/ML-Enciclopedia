## Ball Tree

Ball Tree — это иерархическая структура данных для хранения точек в многомерном пространстве.  
Она использует **вложенные гиперсферы (balls)** для разбиения пространства и применяется для ускорения поиска ближайших соседей (kNN) и пространственных запросов.

---

### 🔹 Принцип работы

1. **Иерархическое разбиение пространства**  
   Пространство рекурсивно разбивается на вложенные гиперсферы.  
   Каждый узел дерева представляет гиперсферу, содержащую подмножество точек.

2. **Вычисление центра узла**  
   Центр гиперсферы определяется как среднее значение всех точек в узле:
   $$
   center = \frac{1}{n}\sum_{i=1}^{n} x_i
   $$

3. **Определение радиуса**  
   Радиус равен максимальному расстоянию от центра до точек узла:
   $$
   radius = \max_i ||x_i - center||
   $$

4. **Разбиение данных**  
   Если количество точек превышает заданный размер листа, данные разделяются на две части:
   - выбирается ось с максимальной дисперсией
   $$
   axis = \arg\max(\mathrm{Var}(X))
   $$
   - точки сортируются по этой оси
   - данные делятся по медиане

5. **Формирование поддеревьев**  
   Рекурсивно создаются два дочерних узла:
   - левое поддерево — первая половина точек  
   - правое поддерево — вторая половина точек

6. **Поиск ближайших соседей (kNN)**  
   При поиске вычисляется расстояние от целевой точки до центра узла.  
   Если выполняется условие:
   $$
   dist(query, center) - radius > d_{best}
   $$
   то весь узел может быть **отсечён**, поскольку он не содержит более близких точек.

---

### 🔹 Использование в kNN

Ball Tree ускоряет поиск ближайших соседей, используя **геометрическое отсечение целых областей пространства**.  
Вместо перебора всех точек алгоритм исследует только те узлы дерева, которые потенциально могут содержать более близкие точки.

---

### ✅ Преимущества Ball Tree

- Хорошо работает в пространствах **средней и высокой размерности**  
- Эффективно выполняет поиск ближайших соседей  
- Использует геометрическое отсечение (pruning) для сокращения числа вычислений  
- Поддерживается во многих библиотеках машинного обучения (например, `scikit-learn BallTree`)

---

### ⚠️ Недостатки Ball Tree

- Построение дерева может быть относительно дорогим по времени  
- Требует дополнительной памяти для хранения структуры дерева  
- При очень высокой размерности эффективность всё равно снижается  
- В некоторых случаях медленнее KD-Tree при низкой размерности
