## K-Dimensional Tree (KD-Tree)

KD-Tree — это бинарное дерево для хранения точек в k-мерном пространстве, позволяющее эффективно выполнять пространственные запросы, такие как поиск ближайших соседей или диапазонный поиск.

---

### 🔹 Принцип работы

1. **Рекурсивное разбиение пространства**  
   Каждое поддерево делит пространство гиперплоскостью, перпендикулярной выбранной оси.

2. **Выбор оси разбиения**  
   На уровне `depth` используется ось:
   $$
   axis = depth \bmod k
   $$

3. **Выбор опорной точки (медиана)**  
   Точки сортируются по выбранной оси, медианная точка становится узлом дерева:
   $$
   node = \text{median}(X_{axis})
   $$

4. **Формирование поддеревьев**  
   - Левое поддерево: точки с меньшим значением по оси  
   - Правое поддерево: точки с большим значением по оси

5. **Поиск ближайших соседей (kNN)**  
   - Сначала рекурсивно обходится ветвь, в которой находится целевая точка  
   - Выполняется backtracking: проверяется необходимость обхода другой ветви  
   - Дальние ветви отсекаются, если гиперплоскость не пересекает текущую сферу поиска

---

### 🔹 Использование в kNN

KD-tree позволяет ускорить поиск k ближайших соседей:  
для каждой точки выбор ближайших k точек выполняется **не перебором всех точек**, а с использованием геометрических отсечений.

---

### ✅ Преимущества KD-Tree

- Ускоряет поиск ближайших соседей по сравнению с brute-force  
- Эффективен при **малой размерности пространства признаков**  
- Сбалансированное дерево уменьшает глубину и количество проверяемых точек  
- Используется в машинном обучении (например, `scikit-learn KDTree`) и задачах геометрического поиска

---

### ⚠️ Недостатки KD-Tree

- Эффективность сильно падает при **высокой размерности признаков** (curse of dimensionality)  
- Динамическое добавление и удаление точек может быть медленным  
- При сильно неравномерных данных дерево может получиться несбалансированным  
- Требуется дополнительная память для хранения структуры дерева
