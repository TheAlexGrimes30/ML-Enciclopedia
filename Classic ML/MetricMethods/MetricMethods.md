## 📏 Metric-Based Machine Learning Methods

Раздел **Metric-Based ML** посвящён алгоритмам машинного обучения, которые основываются на **расстояниях и метриках между объектами**.  
Такие методы особенно хорошо подходят для задач классификации, регрессии и поиска похожих объектов, где ключевую роль играет **сходство между точками в пространстве признаков**.

---

### 🎯 Цель раздела

Понять **математическую основу методов, основанных на метриках**, и научиться их реализовывать **с нуля**.  
Каждый алгоритм сопровождается:

- 📘 **Формальной постановкой** задачи — метрика расстояния, критерий ближайших соседей, формулы вычислений.  
- 💻 **Реализацией на Python / NumPy** без использования готовых библиотек.  
- 🔬 **Сравнением с реализациями из `scikit-learn`** и анализом производительности.

---

### 🔹 Алгоритмы, реализованные в этом разделе

#### 🔹 K-Nearest Neighbors (KNN)
- Классификация и регрессия на основе **евклидового, манхэттенского или косинусного расстояния**.  
- Голосование соседей (classification) или усреднение (regression).  
- Методы ускорения поиска: **KD-Tree, Ball-Tree**.

#### 🔹 KD-Tree
- Бинарное дерево для хранения k-мерных точек.  
- Рекурсивное разбиение пространства гиперплоскостями.  
- Используется для **быстрого поиска ближайших соседей**.  
- **Exact Nearest Neighbor Search** — гарантированно находит реальные ближайшие точки.

#### 🔹 Ball-Tree
- Альтернатива KD-Tree для **высоких размерностей**.  
- Разделение пространства на **сферы (balls)** вместо гиперплоскостей.  
- Эффективен при kNN и диапазонных запросах.

#### 🔹 Distance-Based Clustering
- Кластеризация, основанная на метриках:
  - **Hierarchical Clustering** — агломеративное объединение по минимальному/среднему/максимальному расстоянию.  
  - **DBSCAN** — плотностная кластеризация, использует ε-соседство и минимальное количество точек.  

#### 🔹 Kernel Regression (Nadaraya-Watson)
- **Регрессия на основе ядерных функций**, сглаживающая зависимость между признаками и целевой переменной.  
- Формула оценки для точки \(x\):
$$
\hat{y}(x) = \frac{\sum_{i=1}^n K\left(\frac{\|x - x_i\|}{h}\right) y_i}{\sum_{i=1}^n K\left(\frac{\|x - x_i\|}{h}\right)}
$$
где:
  - \(K\) — ядро (например, гауссово),  
  - \(h\) — ширина окна (bandwidth),  
  - \(x_i, y_i\) — обучающие точки и целевые значения.  
- Сильная связь с KNN: веса соседей определяются **не только топ-k**, а всеми точками с разной «близостью».

---

### ✅ Преимущества Metric-Based ML

- Простая и **интуитивная идея**: объекты ближе в пространстве → похожи.  
- Работает без сложной модели, иногда **без обучения** (lazy learning).  
- Гибкость: можно выбирать разные **метрики расстояния** и **ядра**.  
- Основа для многих алгоритмов поиска, кластеризации и рекомендаций.

---

### ⚠️ Недостатки Metric-Based ML

- Медленная работа при **большом объёме данных**, если нет структур для ускорения поиска.  
- Чувствительность к **масштабированию признаков** — нужна нормализация.  
- При большой размерности (curse of dimensionality) расстояния теряют смысл — ухудшается точность.  
- Не всегда хорошо работает с шумными данными или выбросами.
