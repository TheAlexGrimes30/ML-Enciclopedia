# Decision Tree — Реализация с нуля и сравнение с продакшн-библиотеками

## 🧠 Математическая основа

### 1️⃣ Основная идея
Дерево решений рекурсивно делит пространство признаков на подмножества, в каждом из которых прогноз стремится быть максимально однородным.  
В узле выбирается признак и порог, которые оптимизируют меру «чистоты» (impurity) дочерних узлов.

---

### 2️⃣ Критерии разбиения (classification)

#### Индекс Джини
Для узла с классами 1..K, где `p_k` — доля класса `k`:

**G = 1 − Σ(pₖ²)**

#### Энтропия (Information Entropy)

**H = − Σ(pₖ · log₂(pₖ))**

При выборе разбиения считаем прирост информации (или снижение импурности):

**ΔI = I_parent − [(N_L / N) · I_L + (N_R / N) · I_R]**

где:
- `I` — выбранная мера (Gini или Entropy)  
- `N` — число образцов в узле  
- `N_L`, `N_R` — число образцов в левом и правом дочерних узлах  

---

### 3️⃣ Критерии разбиения (regression)

Для регрессии часто используют MSE (Mean Squared Error):

**MSE = (1 / N) · Σ(yᵢ − ȳ)²**

где `ȳ` — среднее значение `y` в узле.

Прирост качества при разбиении:

**ΔMSE = MSE_parent − [(N_L / N) · MSE_L + (N_R / N) · MSE_R]**

---

### 4️⃣ Критерий останова

Рекурсия по узлам завершается, если выполнено хотя бы одно условие:

- достигнута максимальная глубина `max_depth`;  
- в узле меньше `min_samples_split` объектов;  
- нет улучшения импурности (узел «чист»);  
- (опционально) достигнуто минимальное уменьшение импурности `min_impurity_decrease`.  

---

## ⚙️ Реализация (основные компоненты)

- **Поиск лучшего разбиения**: перебор по признакам и уникальным порогам (или по квантилям для ускорения).  
- **Рекурсивное построение**: создаём лист, если критерии останова выполняются; иначе — разбиваем и строим потомков.  
- **Хранение узла**: признак, порог, ссылки на левый/правый потомок, предсказание (класс или среднее).  
- **Предсказание**: проход по дереву от корня до листа.  

---

## Преимущества и недостатки

### ✅ Преимущества
- Лёгкая интерпретация (можно визуализировать дерево).  
- Не требует масштабирования признаков.  
- Работает с числовыми и категориальными данными (после кодирования).  
- Быстро обучается на средних объёмах данных.  
- Основа для ансамблей — Random Forest, Gradient Boosting.  

### ⚠️ Недостатки
- Склонность к переобучению (без ограничений глубины).  
- Нестабильность: малые изменения данных сильно влияют на структуру дерева.  
- Ступенчатые предсказания — плохо аппроксимируют гладкие функции.  
- При полном переборе порогов медленно работает на больших наборах данных.
