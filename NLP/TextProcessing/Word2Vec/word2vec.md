# Word2Vec – Векторное представление слов и текста

## 1. Обзор

**Word2Vec** — это метод преобразования текста в числовые векторы,  
который, в отличие от Bag of Words, **учитывает смысл слов и их контекст**.

Основная идея:

- Каждое слово представляется **плотным вектором фиксированной размерности**.
- Слова, используемые в похожих контекстах, получают **похожие векторы**.
- Модель обучается предсказывать:
  - либо контекст по слову (**Skip-Gram**),
  - либо слово по контексту (**CBOW**).

Word2Vec используется для:

- Поиска семантически похожих слов
- Классификации текста
- Кластеризации
- Рекомендательных систем
- Подготовки признаков для нейронных сетей
